# The Last Prompt on Mars — build brief

## One-sentence pitch
Mira is an AI assistant running yesterday's mission tape; edit what she remembers, press RUN, and watch the rover finally stop repeating the wrong plan.

## Primary interaction
The player physically edits Mira's glowing mission tape: scratch stale fragments, pin recovered truths, then rerun the rover attempt.

## Why a non-engineer plays
They are not managing "context". They are saving Percy, a small rover carrying a strange blue sample, while Mira keeps obeying an old tape that no longer matches Mars.

## Story spine
- Percy is alive but moving the wrong way.
- Mira is not dumb; she is faithful to stale instructions.
- A ghost signal, collapsed route, and blue crater shadow each reveal why yesterday's plan is dangerous today.
- Final realization: the mission is not just return the rover or protect the sample. Percy and the sample come home together.

## Hidden AI-agent metaphor
- mission tape = working context
- scratch = remove stale context
- pin = preserve a critical constraint
- run = agent execution
- failed rover attempt = output review
- recovered fragment = tool/observation result
- repeated failure = agent stuck on wrong context

## Acceptance criteria
- No text correction panel.
- No dashboard/log UI.
- No generic dust event.
- One clear game verb in 5 seconds: edit tape, run Mira.
- Animated attempts must show cause/effect before the words explain it.
- Shareable outcome should be a run tape/replay, not a dry score.
